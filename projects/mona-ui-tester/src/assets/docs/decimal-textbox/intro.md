# Decimal Text Box

**Selector:** `mona-decimal-text-box`

`DecimalTextBoxComponent` is a numeric input whose value is a decimal string, such as `"1234.56"`, instead of a JavaScript `number`. Use it for money, quantities with many digits, and any value that must not be rounded. It has the same spinner buttons, bounds, decimal formatting, and signal-forms support as the numeric text box, with no precision limit.
