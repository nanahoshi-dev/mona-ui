# Radial

**Selectors:** `mona-radial-bar-series`, `mona-rose-series`, `mona-gauge-series`

Radial bar, rose and gauge series draw values as arcs around a center. A radial bar draws each value as a ring that fills part of a circle, a rose gives each category an equal slice whose length shows its value, and a gauge shows one value on a dial between a minimum and a maximum. Each goes alone inside a `mona-chart`, and only the rose uses axes.
