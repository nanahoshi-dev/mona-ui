# Heatmap

**Selector:** `mona-heatmap-series`

A heatmap series draws a grid of cells, one column per X category and one row per Y category, and colors each cell by its value. It suits values that depend on two categories at once, such as activity by weekday and hour, or a measure by month and year. It goes inside a `mona-chart` on its own, with an X and a Y axis for the category labels and a legend that shows the color scale.
