# Rows

**Selectors:** `ng-template[monaGridDetailTemplate]`, `mona-grid[monaGridRowReorderable]`

A `monaGridDetailTemplate` gives each row an expandable detail row underneath, for content that doesn't fit the columns. `monaGridRowReorderable` adds a drag handle to each row so people can put rows in their own order. Rows also take classes from `rowClass`, and grow to fit their cell templates.
