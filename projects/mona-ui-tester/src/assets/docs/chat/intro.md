# Chat

**Selector:** `mona-chat`

`ChatComponent` shows a conversation, with people or with an assistant: its messages in bubbles, grouped by day and by author, the user's own at the end and others' at the start beside their avatar. Below them, a message box sends with Enter, takes files, and stops a reply while it streams in. Suggested replies and who's typing sit between the two.

You keep the messages. The chat emits what the user sends, and shows what you give it, so a message appears once you add it.
