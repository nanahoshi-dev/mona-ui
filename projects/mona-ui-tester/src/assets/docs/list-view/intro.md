# List View

**Selector:** `mona-list-view`

`ListViewComponent` renders a collection of items as a list, or as a listbox once you can select from it. Keyboard navigation is built in; selection, grouping, pagination and virtual scrolling are each opt-in through a companion directive applied to the same host element.

Import it from `@nanahoshi/mona-ui/list-view`, and name every list view with `aria-label` or `aria-labelledby`. Item templates can hold buttons and links: keys pressed in them reach them.
