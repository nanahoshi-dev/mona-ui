# Chart Overview

**Selector:** `mona-chart`

`ChartComponent` draws charts on a Canvas from parts you write as markup: series, the axes they sit on, and optional parts for the legend, the tooltip, crosshairs, reference lines, annotations, selection and brushing. This page covers what every chart shares: the chart itself, its axes and interaction parts, synchronization between charts, dense data, locale, direction and accessibility. Each family of series has its own page.
