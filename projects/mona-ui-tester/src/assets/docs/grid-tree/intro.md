# Tree List

**Selector:** `mona-grid[monaGridTree]`

`monaGridTree` shows the grid's rows as a tree: each row can have child rows, which show below it, indented, while it's expanded. The data can hold each item's children, or be flat, with each item naming its parent. Sorting, filtering, paging, selection, editing and export all keep working, on the rows as a tree.
