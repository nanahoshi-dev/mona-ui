# Custom Colors

Any theme can take on your brand's colors. Mona UI has three ways to change them, and they combine:

| To                                                                      | Use                                                      |
| ----------------------------------------------------------------------- | -------------------------------------------------------- |
| Generate a complete, accessible palette from your brand colors          | `provideThemeColorPalette()`                             |
| Set specific tokens to exact values, including corner radii and shadows | `provideThemeOverrides()`                                |
| Let users choose a color while the application runs                     | `ThemeService.setPrimaryColor()` and `setColorPalette()` |
