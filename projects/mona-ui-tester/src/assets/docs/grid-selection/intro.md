# Selection

**Selectors:** `mona-grid[monaGridSelectable]`, `mona-grid[monaGridRangeSelectable]`

`monaGridSelectable` lets people select one row or several, with built-in checkboxes, row clicks or the keyboard. The selection is a list of row keys you bind with `[(selectedKeys)]`, so it survives paging, sorting and reloading the data. `monaGridRangeSelectable` selects a rectangle of cells instead, which people copy to a spreadsheet and paste into from one.
