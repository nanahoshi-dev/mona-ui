# Sorting & Filtering

**Selectors:** `mona-grid[monaGridSortable]`, `mona-grid[monaGridFilterable]`

`monaGridSortable` sorts rows when a column header is activated, by one column or several. `monaGridFilterable` adds filter controls to each column, in a header menu, a filter row under the headers, or both. Both keep their state in a two-way model you can also set from code.
