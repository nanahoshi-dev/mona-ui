# Columns

**Selectors:** `mona-grid[monaGridResizable]`, `mona-grid[monaGridReorderable]`

`monaGridResizable` adds a drag handle between column headers, and `monaGridReorderable` lets people drag headers into a new order. A column's own inputs set its width, lock it to one side while the grid scrolls sideways, or hide it, and the toolbar's Columns button lets people choose which columns they see.
