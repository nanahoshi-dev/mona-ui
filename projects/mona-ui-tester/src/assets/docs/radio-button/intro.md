# Radio Button

**Component selectors:** `mona-radio-button` · `mona-radio-group` &nbsp;·&nbsp; **Directive selector:** `input[type='radio'][monaRadioButton]`

`RadioButtonComponent` renders a fully styled radio button with a managed label and signal forms support. `RadioGroupComponent` holds one value for the radio buttons inside it. `RadioButtonDirective` applies the same visual style to a native `<input type="radio">` that consumers place and label themselves.
