# Pager

**Selector:** `mona-pager`

Pager renders pagination controls — numeric page buttons, previous/next/first/last navigation, an optional page-size selector, and an optional page-jump input — for navigating a paged collection of items.

With zero items, the summary shows `0 - 0 of 0 items` in the active locale. All page navigation buttons are disabled, custom navigation templates receive `disabled: true`, and the page-jump input is hidden. The numeric pager's page-size selector remains available.
