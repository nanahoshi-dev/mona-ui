# Editor

**Selector:** `mona-editor`

Editor is a rich text editor with a configurable toolbar. Its value is HTML, and it works with `[(value)]` and signal forms through `[formField]`.

The editor needs packages and styles that the other components don't, so Mona UI doesn't install them. Before you use it, follow [Set Up the Rich Text Editor](/components/installation#set-up-the-rich-text-editor).

Give it a name with a `<label>` and `aria-labelledby`, or with `aria-label`. A placeholder is not a name.
