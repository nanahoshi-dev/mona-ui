# Timeline

**Selector:** `mona-timeline`

`TimelineComponent` shows events in order along a line: each event's date, a marker on the line, and a card with its title, subtitle and description. It runs down the page, with the cards on one side of the line or on alternating sides, or across it. On a collapsible timeline, each card's header opens and closes its details.

Screen readers read it as an ordered list. Each event's date comes first, then its title, which is a heading.
