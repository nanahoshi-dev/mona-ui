# Sidebar State & Behavior

**Selectors:** `mona-sidebar`, `mona-sidebar-layout`, `[monaSidebarTrigger]`

How a [sidebar](/components/sidebar) opens and closes: what collapsing does, binding its state with `[(expanded)]`, remembering it across reloads with `persistKey`, reading and driving it from code with `injectSidebar()`, and the modal drawer it becomes on small screens.
