# Tree View

**Selector:** `mona-tree-view`

`TreeViewComponent` renders hierarchical or flat parent-child data as an expandable, keyboard-navigable tree of nodes, with selection, checking, disabling, expand/collapse, filtering and drag-and-drop each opt-in through a companion directive. Nodes moved by drag and drop can also be moved with Ctrl+Shift+arrow keys; either way the tree asks through `nodeDrop`, and your handler applies the move.
