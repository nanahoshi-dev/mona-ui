# Segmented

**Selector:** `mona-segmented`

`SegmentedComponent` renders a compact set of mutually exclusive options as a native radio group. Exactly one option is selected at a time, and the control reports the selected value through a two-way `value` model.

Segmented controls are the right choice when a small set of options should share a single selection, for example `List | Grid` or `Day | Week | Month`. They are not a content-switching mechanism — use `TabsComponent` when each option reveals a separate content panel.
