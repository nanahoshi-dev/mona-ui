# Masked Text Box

**Selector:** `mona-masked-text-box`

`MaskedTextBoxComponent` is a text input for values in one fixed format, such as a phone number, a postal code or a product key. Each character goes into a slot of the mask, the mask's own characters, such as the parentheses and dash of `(000) 000-0000`, are filled in as you type, and the rest of the format shows after what's typed. A character a slot doesn't take is turned down, and screen readers say what the slot takes.
