# Grouping & Aggregates

**Selectors:** `mona-grid[monaGridGroupable]`, `ng-template[monaGridFooterTemplate]`, `ng-template[monaGridGroupFooterTemplate]`

`monaGridGroupable` lets people drag column headers into a group panel above the grid, and nests the rows under one expandable header per value. A column's `aggregate` adds a sum, average, count, minimum or maximum to the grid footer and to each group's footer.
