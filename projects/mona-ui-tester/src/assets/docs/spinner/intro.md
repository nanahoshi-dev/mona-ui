# Spinner

**Selector:** `mona-spinner`

**Entry Point:** `@nanahoshi/mona-ui/spinner`

`SpinnerComponent` is a lightweight inline visual primitive for communicating indeterminate loading states. It supports multiple appearances (`default`, `pulsing`, `pulsing-triad`, `pulsing-ring`, `converging-spinner`), standard sizes, and semantic color inheritance.

`SpinnerService` is an imperative orchestration service for showing loading overlays over targeted elements or the full page, supporting concurrency deduplication, delays, minimum visible durations, and cancellation.
